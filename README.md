# Docker

L'applicaton permet de forger des armes de differents materiaux et forme aisnsi que leur donner un nom

Il faut installer docker

le .env est a creer a base du .env.example en remplacant les trois valeurs par d'autres de votre choix.

Il faut ensuite mettre dans le terminal la commande :
    docker compose up -d --build

url de l'app : http://localhost:8000/
url de adminer : http://localhost:8080/

autocompletion pour rentre dans adminer, sinon remplir les credentials de votre env
